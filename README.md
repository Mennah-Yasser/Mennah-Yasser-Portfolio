# Mennah Yasser — portfolio

A responsive, dependency-free personal portfolio site for Mennah Yasser. Open `index.html` directly in a browser or serve the `outputs` directory with any static file server. No build step is required.

## Update content

- Edit `content.js` to update skills, services, project descriptions, technologies, repository URLs, and demo URLs.
- Add project screenshots to `assets/` and extend the project data/rendering in `script.js` when they are available.
- Contact details and profile links are in `index.html`.

The contact form validates fields and opens a `mailto:` draft; it does not send messages or use a backend. A repository action appears only for projects with a supplied URL. Only Luxora currently has a project repository URL.
